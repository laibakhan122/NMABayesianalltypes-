# BayesMetaNMA
An interactive R/Shiny application for Bayesian pairwise and network meta-analysis.

## Installation
Requires R (>=4.0.0), Shiny (>=1.7.0), and JAGS installed locally.

## Usage
Run `shiny::runApp("path/to/app")` after cloning the repository.
